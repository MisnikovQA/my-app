# 🖥️ System Dashboard App

A simple **Next.js + TypeScript** web dashboard that displays system information such as CPU usage, memory usage, and temperature.

## 🚀 Features
- Displays CPU, memory, and temperature stats
- Uses **Next.js 15**, **Tailwind CSS**, and **shadcn/ui**
- Designed for mini PCs or Ubuntu servers

## ⚙️ Setup

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev
# Open http://localhost:3000

# 3. Build for production
npm run build
npm run start
````

## 📂 Project Structure

```
src/
 ├─ app/          → Pages and layout
 └─ lib/system.ts → System information logic
```

## 🧰 UI Components

This project uses [`shadcn/ui`](https://ui.shadcn.com) for cards and progress bars.
